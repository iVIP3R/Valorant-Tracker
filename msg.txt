v0.5 - Resilience & Logging

This milestone marks the completion of Phase 5. The application is now production-ready and handles unexpected failures gracefully.

Highlights:
- Global Exception Handling: Added a global try/catch in Program.cs for both UI and background threads.
- Custom Logging: Added a lightweight Logger that writes detailed stack traces to %LOCALAPPDATA%\Valorant_Tracker\logs\.
- User-Friendly Errors: Replaced raw Windows crash dialogs with clean, actionable error messages (e.g., distinguishing between expired sessions and lost internet).
- Zero Crashes: The app will no longer hard-crash if the network drops or Riot's API changes unexpectedly.
