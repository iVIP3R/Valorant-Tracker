v0.4 - Core Functionality Complete

This milestone marks the completion of Phases 3 and 4. The application is now fully async, dynamically fetches game data, and handles match history with high performance.

Highlights:
- Async Refactor: Player details, balances, and XP now use native async/await, eliminating blocked threads.
- Rank Dictionary: Replaced a 75-line switch statement with a fast, case-insensitive dictionary lookup.
- Smart Match History: Implemented progressive background loading for match details, coupled with an in-memory cache.
- Instant Details: Clicking a match row now opens the detailed scoreboard instantly (0ms delay) by passing the cached object directly to the form.
- API Fixes: Fixed uppercase region codes in Balances and AccountXP that were causing silent failures.
